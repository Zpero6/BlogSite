## 先明确问题，再选择技术

个人博客首先是一个内容产品。让访问者找到文章、读懂文章，比展示技术栈更重要。

这是用于验证页面排版的示例文章，不代表已经完成的项目复盘。

## 第一版的边界

- Astro 负责页面、SEO 和阅读体验。
- Markdown 是文章内容源。
- Cloudflare Pages 负责静态托管。

## 为什么选择静态架构

不需要常驻服务器，也不需要为了写文章维护数据库。构建过程把内容转换成普通 HTML。

```text
Markdown → Astro build → HTML / CSS / JS
```

## 演进方向

先完成文章发布与阅读闭环，再基于真实需求增加评论或统计。
