# Zpero adaptation

This frontend is based directly on XinghuisamaBlogs:

- https://github.com/heiehiehi/XinghuisamaBlogs
- Upstream commit: 8633e983371acc3b627b88b911143ff0fd31ea23
- License: CC BY-NC 4.0 (see LICENSE)

Changes include Zpero branding, original local SVG backgrounds, local avatar placeholder,
Java-oriented sample posts, reduced navigation, removal of upstream personal content,
and a rewrite for the Spring Boot /api/v1 backend.

The original author's avatars, wallpapers, articles, contact details and music IDs are not used.
