# Site-card illustrations

`scripts/generate-nav-art.mjs`. Each module has a different glyph and tint; they
are not copied from the reference site and are deliberately easy to replace.

## Replacing an illustration

1. Drop a square image into this directory. 120×120 or larger with a
   transparent background works best.
2. Point the matching `imageSrc` in
   `components/home/NavigationGrid.tsx` at the new file.
3. If the artwork needs different sizing or cropping, set `imageSize`
   (default `56`) and `imagePosition` on that item.

The card uses `object-contain`, so the full image stays visible. No JSX changes
are needed for a simple asset swap.
